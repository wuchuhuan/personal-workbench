# 个人工作台（个人使用版）

这是一个部署在 GitHub Pages、供账号 `wuchuhuan` 个人使用的工作台网页；可在 iPhone Safari 中“添加到主屏幕”后像 App 一样打开。

## 原始项目与致谢

本仓库基于 [Qiang-Z/personal-workbench](https://github.com/Qiang-Z/personal-workbench) 的个人工作台项目整理而来。

- 原项目的代码、设计与功能版权归原作者及贡献者所有。
- 本仓库不主张拥有原项目的著作权，仅保存个人部署所需的静态文件和适配说明。
- 本次调整仅包括 iPhone/PWA 安装支持、离线缓存、发布入口及静态资源路径适配。
- 原项目说明中允许个人使用和自行修改；如需公开传播、商用或二次发布，请自行核实并遵循原项目的全部约定。

## 数据与隐私

- 项目、任务、计划等数据默认只保存在每台设备的浏览器本地。
- 本仓库和 GitHub Pages 不会自动上传你的工作台数据。
- 如启用“更多 → 云端同步”，数据会保存到你自己的私有 GitHub Gist；请勿把 Token、API Key、密码或个人隐私数据提交到本仓库。
- 本地 AI Companion 与 Obsidian 连接仅在运行 Companion 的电脑可用，手机不直接连接电脑的本地服务。

## iPhone 使用

1. 在 iPhone Safari 打开发布后的网址。
2. 点击“分享”。
3. 选择“添加到主屏幕”。
4. 从主屏幕图标打开个人工作台。

首次联网访问后，常用页面可离线打开；联网时可继续使用同步功能。

## 同步提醒

电脑与 iPhone 需在“更多 → 云端同步”中配置同一个私有 Gist。同步为整份工作台数据同步，建议一台设备保存并完成同步后，再在另一台设备继续编辑，避免后保存的版本覆盖前一份内容。

仅限个人学习、个人效率管理与个人设备使用。此仓库不是原项目官方发行版，也不提供对外服务或商业支持。
